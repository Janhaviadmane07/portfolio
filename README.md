## 📋 About

This is my personal developer portfolio — a fully animated, responsive single-page web application built with **Vite + Vanilla JS**. It showcases my skills, featured projects, IoT patent, certifications, education, and contact info, with a polished dark/light theme toggle and micro-animations throughout.

---

## ✨ Features

- 🌗 **Dark / Light Theme Toggle** with smooth CSS transitions
- 🎨 **Animated Hero Section** with interactive particle canvas and floating tech badges
- ⌨️ **Typing Animation** cycling through specializations
- 🗂️ **Filterable Skills & Projects Grid** — filter by category (AI, Full-Stack, IoT, Cloud)
- 📜 **Inline Resume Viewer** — PDF embedded directly in the About section
- 🏅 **Certifications Showcase** with lightbox modal viewer
- 🪄 **Patent Spotlight Section** with official gazette document preview
- 📫 **Contact Section** with direct email, phone, GitHub, and LinkedIn links
- 🎉 **Confetti** animation on certain interactions (canvas-confetti)
- 📱 **Fully Responsive** — hamburger nav on mobile
- ⚡ **SEO Optimized** — meta tags, semantic HTML, descriptive titles

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) v18+
- npm v9+

### Installation & Development

```bash
# Clone the repository
git clone https://github.com/Janhaviadmane07/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server (hot reload)
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build

```bash
npm run build       # Outputs to dist/
npm run preview     # Preview the production build locally
```
